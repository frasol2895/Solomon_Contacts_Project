# Frank Solomon - Week 4 Contacts Application
## 4.2 Project: Database Interactions

Requires JDK 17 or newer. Extract the entire ZIP. On Windows double-click run.bat.
On Linux/macOS run: sh run.sh
SQLite JDBC and its logging dependencies are included in lib.

Welcome instructions and menu appear at startup. Choose 1 to display all,
2 to search by last-name initial, 3 to add, 4 to update, 5 to delete, or 0 to exit.
Update and delete use the displayed contact ID. Press Enter during update to
keep an existing value. Delete requires YES. Type /cancel to abandon an operation.

contacts.db includes three realistic fictional sample contacts, one of each type.
Edits persist after closing the program. Samples are not reinserted at startup.
The single contacts table stores common fields, address fields and subtype details.
